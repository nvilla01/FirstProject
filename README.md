# Lab: Shopping Receipt

This program asks for users item, price, and quality, and prints the receipt

## How to Run
1. Open the program in your IDE.
2. Enter item, price, and quality
3. View the calculated total and receipt.

## Example Output
Enter item name: Milk

Enter price: 3.49

Enter quantity: 2

Receipt saved!
